# ITACHI-MD
WhatsApp bot using Baileys pairing code, Gemini, Search and Weather.

## تشغيل
npm install
npm start

## متغيرات Render
GEMINI_API_KEY=مفتاح Gemini
GEMINI_MODEL=gemini-3.6-flash
OWNER_NUMBER=رقم واتساب بصيغة دولية بدون +
SERPAPI_KEY=اختياري
WEATHER_API_KEY=اختياري

عند أول تشغيل سيظهر Pairing Code في السجل.
لا ترفع مجلد itachi_auth إلى GitHub.
